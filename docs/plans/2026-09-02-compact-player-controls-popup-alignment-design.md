# 紧凑播放控制栏与 Popup 对齐设计

## 目标

缩小移动端底部播放按钮及按钮间距，让播放模式按钮从屏幕边缘向内移动。在 360px 宽度下，128px 播放模式 popup 可以与模式按钮严格居中，同时完整保留在屏幕 8px 安全边距内。

## 布局

- 用一个居中的对称 `Row` 取代“左右按钮贴边 + 中间运输按钮 Stack”的布局。
- 模式、上一首、下一首、队列按钮均保持 48×48 触控区域，图标统一为 24px。
- 播放/暂停按钮缩小为 56×56，图标缩小为 30px。
- 五个按钮之间使用四个 4px 间距，总宽度为 264px。
- 在 360px 宽度下，模式按钮中心位于 72px，128px popup 左边界为 8px，因此无需边界修正即可严格对齐。
- 低于 360px 的屏幕继续由 popup 边界保护逻辑保证完整显示。

## 验证

- 在 360px 视口断言控制栏总宽度和各按钮尺寸。
- 打开 popup 后断言 popup 与模式按钮中心线误差不超过 1px，并保持至少 8px 左边距。
- 保持中央播放按钮位于页面中心，上一首和下一首关于中心对称。
- 保持所有按钮操作委托与模式切换测试通过。
